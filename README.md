# SkyCast Weather Dashboard

A responsive  weather dashboard using the OpenWeatherMap API. Search and save cities, view current conditions, and open a 5-day forecast.

## Requirements
- Python 3.11 or newer
- An OpenWeatherMap API key (free account is sufficient for current weather; forecast access depends on your API plan)
- Internet connection


  



The project uses SQLite by default. The database is created/updated by Django migrations; no separate database server is needed.
